# SillyTavern Classic

A SillyTavern look for Lumiverse: top icon bar, flat message cards, Noto Sans, ST-style controls. Follows your theme colours, Font Scale, UI Scale, Corner Radius, light mode and wallpaper.

- **SillyTavern Classic.lumitheme**: Loom and Presets dock left, Characters and Profile dock right, other panels open centred under the bar.
- **SillyTavern Classic (Side Panels).lumitheme**: every panel docks to the side chosen in the Drawer Side setting.

Import from Settings > Theme. If a Lumiverse update ever breaks the layout and you can't reach the Theme tab, open Lumiverse with `?safe-theme=1` at the end of the URL to turn custom CSS off.
